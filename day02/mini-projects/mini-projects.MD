## Overview
Python projects created while learning the fundamentals of Python.

The goal of these projects is to practice concepts through simple, practical programs with random examples and learn fundamentals on the go.

## Projects
### 1. BMI Calculator — `bmi_calculator.py`
A simple program that:
- Takes height and weight as input.
- Calculates BMI.
- Classifies the result based on BMI ranges.
- Practices user input, type conversion, arithmetic, and `if` / `elif` / `else`.

### 2. Number Analyzer — `number_analyzer.py`
A program for analyzing an integer entered by the user:
- Checking whether input is empty.
- Using `.strip()`.
- Validating an integer using `.lstrip("-").isdigit()`.
- Converting valid input to an integer.
- Determining whether a number is positive, negative, or zero.
- Determining the parity check - even or odd.
- Determining the magnitude if the num is small, medium, huge
- A small check on divisibility
- Using conditional logic.

### 3. Temperature Advisor — `temperature_advisor.py`
A program that classifies/advises based on temperature:
- Numeric input.
- Comparisons.
- Numeric ranges.
- `if` / `elif` / `else`.

### 4. Quick Decision Maker — `quick_decision_maker.py`
A simple interactive Python program that helps the user make everyday decisions based on a few questions.
The program provides three scenarios:

- Should I go out? — considers the weather and tiredness.
- What should I eat? — suggests food based on the user's budget.
- Should I study or relax? — considers energy level and upcoming deadlines.

Concepts Practiced
- input() and user interaction
- .strip() and .lower() for cleaning user input
- if, elif, and else
- Nested conditionals
- String comparison
- Logical decision-making
- Handling invalid choices
- Basic input validation


## Intentional Learning Limitation

### `try` / `except` is intentionally not used yet

These projects may contain situations where `try` / `except` would be the best way to handle invalid user input. Will try to cover on a later stage
when i learn try and except exclusively and revisit these mini projects
with a different prespective.
